- [x] CHK002 詳細設定画面 (FR-013) で変更可能とされる項目の一覧は、Key Entities に列挙された全設定項目と過不足なく対応しているか [Completeness, Spec §FR-013]

- [x] CHK003 二重起動時の挙動 (Edge Cases) について、フォーカス移動・無視のどちらでもよいとする範囲が明記されているか [Completeness, Spec §Edge Cases]

- [x] CHK004 アプリ終了操作 (Assumptions) に対応する Functional Requirement が存在するか、または意図的に Assumptions のみに留めているかが明確か [Completeness, Gap, Spec §Assumptions]

- [x] CHK005 モニタの取り外し・再接続時に「同一モニタ」と判定する基準についての要求が定義されているか [Completeness, Gap, Spec §Assumptions]

## Requirement Clarity (要求の明確性)

- [x] CHK006 FR-002 の「1 秒以内の周期」は、表示更新間隔として一意に解釈できるか (正確に 1 秒ごとか、それ以下の任意間隔でもよいか) [Clarity, Spec §FR-002]
  - 所見: 問題なし。「1 秒以内の周期」は「更新間隔は 1 秒以下であればよい」と一意に読める
- [x] CHK007 FR-012 の「その場で切り替えられる」が指す操作の範囲 (右クリックメニュー上のクリックのみか) が明確か [Clarity, Spec §FR-012]
  - 所見: 問題なし。FR-013(詳細設定画面)との対比で、右クリックメニュー上での即時切替を指すと文脈上明確
- [x] CHK008 SC-001 の「5 秒以内」の計測起点 (ユーザーのログイン操作完了時点か、OS のログイン処理完了時点か) が明確か [Clarity, Spec §SC-001]
  - 所見: 解消済み。/speckit-clarify (2026-09-17) で SC-001 に「デスクトップが操作可能になった時点(OS 側のログイン処理時間は含まない)」と明記した
- [x] CHK009 SC-006 における「アイドル時」の定義 (時計表示更新のみが発生している状態か、詳細設定画面が非表示の状態か) が明確か [Clarity, Spec §SC-006]
  - 所見: 解消済み。/speckit-clarify (2026-09-17) で SC-006 に「詳細設定画面を閉じている間」を明記し、開いている間は対象外とした

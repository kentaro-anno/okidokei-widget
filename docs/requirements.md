# Windows 11 常駐時計アプリ 要件定義書

## 概要
Microsoft Store の既存ウィジェットで満足できるものがなかったため、自作する。
Windows 11 上で動作する常駐型のデスクトップ時計アプリ。

## 技術スタック
- WPF / C#(.NET)を想定(実装時に妥当性を再検討して良い)
- 設定の保存形式: JSON ファイル(レジストリは使わない)

## 基本動作
- 常駐アプリとして起動
- Windows 起動時に自動起動する

## 表示内容
- 時刻(必須)
- 日付
- 曜日
- フォント種類を設定可能
- フォントサイズを設定可能
- 文字色を設定可能

## ウィンドウ挙動

### 最前面表示
- 常に最前面にするかどうかを設定で ON/OFF 切替可能

### 配置
- ドラッグによる自由配置
- 位置を「固定(ロック)」する機能(誤操作でのズレを防止)

### 背景
- 透過度をスライダー等で設定可能(0〜100%)

### デザイン
- シンプルかつモダンな見た目(角丸・軽い影など、実装時に Claude Code の裁量で調整して良い)

## マルチモニタ対応
- モニタごとに表示 / 非表示を切替可能
- モニタごとに独立した表示位置を保持できる
  (例: モニタ A では右上に表示、モニタ B では非表示、など)

## 設定 UI

### 右クリックメニュー(クイック切替)
- 最前面表示 ON/OFF
- 位置ロック ON/OFF
- 表示 / 非表示

### 別ウィンドウ(詳細設定)
- フォント種類・サイズ・色
- 背景透過度
- モニタごとの表示設定
- 自動起動の ON/OFF

## 設定の保存
- JSON ファイルとして保存(アプリと同じフォルダ、または `%APPDATA%` 配下を想定)
